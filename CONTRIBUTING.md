# Contributing

Run `node web/tests/model.test.mjs` and `python -m unittest discover -s tests -v`, plus the README workflow. Preserve units, numerical stability, model-domain flags, signed measurement support and web/Python parity. New models need explicit domains, equations, source references, uncertainty and validation evidence.

Keep idealized calculations distinct from measured performance. Do not describe Shannon bounds as measured throughput or delay/bin arithmetic as validated detection/accuracy. Do not treat hashes or software tests as authenticity, novelty or approval. Protect credentials and unpublished partner data. Submit focused pull requests with behavior and verification evidence.
