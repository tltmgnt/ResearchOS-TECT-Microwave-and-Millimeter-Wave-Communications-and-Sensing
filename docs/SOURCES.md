# Primary sources

Reviewed November 16, 2026.

- [ITU-R P.525, Calculation of free-space attenuation](https://www.itu.int/rec/r-rec-p.525): primary reference for the free-space loss context. This repository implements the explicitly documented idealized equation, not a complete propagation planning standard.
- [NIST Boltzmann constant](https://physics.nist.gov/cuu/Constants/Value/k.html): k = 1.380649×10⁻²³ J/K.
- [DARPA Strategic Technology Office](https://www.darpa.mil/about/offices/sto): research context only, not endorsement or eligibility.
- [DARPA opportunities](https://www.darpa.mil/work-with-us/opportunities): check the actual applicable solicitation, scope, instructions and amendments before any engagement.

All example antenna gains, powers, losses, bandwidths and delays are synthetic fixtures, not DARPA requirements or calibrated hardware parameters. Model bounds, assumptions and explicit formulas are defined in MODEL.md. This source list does not establish novelty, certification or field performance.
